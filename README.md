# WarrantyIDEA

**WarrantyIDEA** adalah platform digital untuk membantu toko komputer dan elektronik mengelola garansi dan layanan setelah pembelian dengan lebih mudah dan teratur.

Setiap produk memiliki **QR Code** yang dapat dipindai pelanggan untuk melihat informasi garansi, riwayat servis, dan mengajukan klaim.

## Fitur Utama

- Digital warranty melalui QR Code
- Informasi masa berlaku garansi
- Pengajuan klaim garansi
- Riwayat servis produk
- Pencatatan serial number
- Pencatatan kondisi barang
- Dashboard untuk seller
- Riwayat pelanggan

## Manfaat

**Untuk Seller**
- Pengelolaan data garansi lebih rapi
- Memudahkan pengecekan klaim
- Menyimpan riwayat servis produk
- Membantu menjaga hubungan dengan pelanggan

**Untuk Customer**
- Informasi garansi mudah diakses
- Tidak perlu mencari kartu garansi fisik
- Pengajuan klaim lebih praktis
- Riwayat servis tersimpan secara digital

## Konsep

WarrantyIDEA menghubungkan **seller, produk, dan customer** dalam satu sistem sehingga proses setelah pembelian menjadi lebih mudah bagi kedua pihak.
